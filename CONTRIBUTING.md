# Contributing

Open an issue with the topic, platform, Python/browser versions, selected rendering backend, expected result and a minimal reproducible scene. Remove credentials and personal information from logs.

For changes, explain the observable problem and include only the checks that address it. Verify Python syntax and script help, relative documentation links, exact frame counts and repeated cross-scene captures when applicable. Scene changes should include contact sheets and a normal-speed audiovisual review or a clear note that this review is outstanding. Do not add unlicensed media or claim universal quality from one example.

Contributions are submitted under the repository MIT license; preserve all third-party notices.
